OFICINA DE TRABAJO VIRTUAL v4.5.0 - ADMINISTRADOR EN RENDER

URL del administrador:
https://oficina-trabajo-virtual.onrender.com/admin

Comprobaciones de Render:
1. El servicio debe ser Web Service con Runtime = Docker.
2. Dockerfile: ./Dockerfile
3. Docker Context: .
4. Health Check Path: /health
5. El contenedor escucha en 0.0.0.0 y usa PORT de Render automáticamente.
6. El disco persistente debe montarse en /app/data para conservar la base SQLite.

Rutas de diagnóstico:
/health   -> salud del servicio
/ready    -> preparación del servicio y base de datos
/_render  -> diagnóstico de entorno Render
/admin    -> panel administrativo

Variables necesarias en Render:
PASSWORD_PEPPER (Render Generate Value)
RESEND_API_KEY
EMAIL_FROM
ADMIN_EMAIL

Después de desplegar, prueba primero /health y luego /admin.
